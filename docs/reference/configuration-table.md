| Setting | Environment variable | Type | Default | Meaning |
|---|---|---|---|---|
| `ai.provider` | `MAITHIC_PROVIDER` | `anthropic` \| `openai` \| `xai` \| `local` \| `mock` | `anthropic` | The model provider used for every AI call. |
| `ai.tier` | `MAITHIC_TIER` | `fast` \| `balanced` \| `best` | `balanced` | Quality tier, resolved to a model identifier through the model registry. |
| `ai.model` | `MAITHIC_MODEL` | string | (empty) | An explicit model identifier. Overrides the tier when set. |
| `gateway.mode` | `MAITHIC_GATEWAY_MODE` | `live` \| `record` \| `replay` \| `mock` \| `off` | `live` | live calls the provider; record also saves cassettes; replay answers from cassettes only; mock returns canned answers; off disables AI. |
| `gateway.cassette_dir` | `MAITHIC_CASSETTE_DIR` | path | `fixtures/cassettes` | Where cassettes are read and written. |
| `gateway.models` | `MAITHIC_MODELS` | path | (empty) | A model registry file that replaces the built-in one. |
| `gateway.prompts` | `MAITHIC_PROMPTS` | path | (empty) | A directory of prompt files that override the built-in prompts. |
| `gateway.timeout_s` | `MAITHIC_GATEWAY_TIMEOUT` | number | `120` | Deadline of one provider call, in seconds. |
| `gateway.max_tokens` | `MAITHIC_MAX_TOKENS` | integer | `2048` | Upper bound on the tokens generated by one call. |
| `bridge.command` | `MAITHIC_BRIDGE` | string | (empty) | Path of the maithic-bridge executable. Discovered when empty. |
| `bridge.project` | `MAITHIC_LEAN_PROJECT` | path | (empty) | A Lake project directory. When set, the Bridge runs through `lake env` there and sees the project's modules. |
| `bridge.lake` | `MAITHIC_LAKE` | string | `lake` | The lake command used with bridge.project. |
| `bridge.timeout_s` | `MAITHIC_BRIDGE_TIMEOUT` | number | `120` | Deadline of one Bridge request, in seconds. |
| `bridge.max_heartbeats` | `MAITHIC_MAX_HEARTBEATS` | integer | `0` | Deterministic step budget of one elaboration, in thousands of heartbeats. 0 keeps Lean's default. |
| `prove.use_ai` | `MAITHIC_USE_AI` | boolean | `true` | Ask the model for proofs when the automation portfolio fails. |
| `prove.rounds` | `MAITHIC_ROUNDS` | integer | `3` | Model rounds per theorem; each round sees the errors of the previous one. |
| `prove.candidates` | `MAITHIC_CANDIDATES` | integer | `4` | Proof candidates requested from the model in each round. |
| `prove.search` | `MAITHIC_SEARCH` | boolean | `false` | Search for a proof one tactic at a time when the automation portfolio fails, before any model is asked. |
| `prove.search_expansions` | `MAITHIC_SEARCH_EXPANSIONS` | integer | `60` | Goals the step-wise search may expand for one theorem. |
| `prove.oracle` | `MAITHIC_ORACLE` | boolean | `false` | Ask the oracles for a certificate when the automation portfolio fails on an arithmetic goal. |
| `oracle.julia` | `MAITHIC_JULIA` | string | `julia` | The Julia executable that runs the oracle engines and the guidance service. |
| `oracle.project` | `MAITHIC_ORACLE_PROJECT` | path | (empty) | The directory of the Julia package MaithicOracle. Found in the source tree around the current directory when empty. |
| `oracle.timeout_s` | `MAITHIC_ORACLE_TIMEOUT` | number | `60` | Seconds an oracle may take to answer one goal. |
| `guide.model` | `MAITHIC_GUIDE_MODEL` | path | (empty) | A trained tactic model. When set, it orders the candidates of every step-wise search; `prove --guide` sets it for one run. |
| `guide.project` | `MAITHIC_GUIDE_PROJECT` | path | (empty) | The directory of the Julia package MaithicGuide. Found in the source tree around the current directory when empty. |
| `guide.timeout_s` | `MAITHIC_GUIDE_TIMEOUT` | number | `30` | Seconds the guidance service may take to answer one question. |
| `nnv.project` | `MAITHIC_NNV_PROJECT` | path | (empty) | The directory of the Julia package MaithicNNV. Found in the source tree around the current directory when empty. |
| `nnv.timeout_s` | `MAITHIC_NNV_TIMEOUT` | number | `120` | Seconds the network verifier may take to decide one property. |
| `algolab.project` | `MAITHIC_ALGOLAB_PROJECT` | path | (empty) | The directory of the Julia package MaithicAlgoRef. Found in the source tree around the current directory when empty. |
| `ledger.policy` | `MAITHIC_POLICY` | path | (empty) | A trust policy file. The strict built-in policy applies when empty. |
| `log.level` | `MAITHIC_LOG_LEVEL` | `quiet` \| `normal` \| `verbose` | `normal` | How much the commands print. |
