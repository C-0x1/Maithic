# Getting help

- **Questions and ideas:** open a discussion or an issue in the repository.
- **Bugs:** open an issue with the output of `maithic doctor --json`, the command you ran and what happened.
  Remove anything private first; `doctor` never prints a key.
- **Security problems and conduct reports:** write to the maintainers at `maintainers@example.org`.

The address above is the placeholder from [`PROJECT.toml`](PROJECT.toml); the repository owner replaces it.
